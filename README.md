## Getting Started

**Prerequisites:** Node.js 18 or newer.

```bash
# 1. Install dependencies
npm install --legacy-peer-deps

# 2. Start the development server
npm run dev
```

The site runs at `http://localhost:3000`.

### Build for production

```bash
npm run build
npm run preview
```

## Customizing the Content

- **Text and data:** edit `src/data/PortfolioData.ts` (projects, experience, education, certifications)
- **Skills:** edit `src/components/Skills.tsx`
- **Contact details:** edit `src/components/Contact.tsx`
- **Resume PDF:** replace `public/documents/resume.pdf`
- **Profile photo:** replace `public/img/me.svg` or add `public/img/me.png` and update the path in `src/components/Hero.tsx`
